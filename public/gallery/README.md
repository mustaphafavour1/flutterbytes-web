# Gallery highlights

Drop 10–20 curated event photos in this folder. They appear on the homepage
gallery strip and in the "Highlights" grid on the `/gallery` page.

## Naming

- Any name works: `opening-2025.jpg`, `crowd.png`, etc.
- Any image extension: `.jpg`, `.png`, `.webp`, …
- **Optional `N-` prefix** to control order (lower = first): `1-keynote.jpg`,
  `2-crowd.jpg`. Unnumbered files sort alphabetically after the numbered ones.

Keep it to a curated handful — the full albums for each year are linked on the
`/gallery` page (edit those links in `src/app/gallery/page.tsx`).
