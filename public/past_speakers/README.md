# Past speaker photos

Drop each past speaker's picture in **this** folder (`public/past_speakers/`).

## Naming

- Name the file after the person, lowercase with hyphens: `odinachi-david.jpg`
- **Any image extension works** — `.jpg`, `.png`, `.webp`, etc. Use whatever you have.
- **Optional ordering prefix:** put `N-` in front to control who shows first
  (lower number = earlier). No prefix needed until you want to pin an order.
  - `1-odinachi-david.jpg` → shown 1st
  - `8-kudus-rufai.png`    → shown 8th
  - `sasha-denisov.jpg`    → no prefix → shown after all the numbered ones
- Square images look best (~400×400px).

Numbered files sort ascending and appear first (great for the wheel's first set of
8); everyone without a number keeps the list order after them. Until a photo is
uploaded, that speaker shows an initials avatar — so you can add them gradually.
