# Sponsor logos

logo, so no name is shown under the chip — only a tier label when the sponsor has
one. Tiered sponsors are listed first. Each chip links to the sponsor's website.

Edit the list (names, logo filename, website, tier) in
`src/components/sections/SponsorsSection.tsx`.
