# Sponsor logos

Drop each sponsor's logo here named exactly as listed below. **`.png` with a
transparent background** works best. Recommended: ~300px wide, any height (it's
scaled to fit a 48px-tall slot).

Until a file exists, that sponsor shows an initials monogram — the brand name and
tier label always show regardless.
